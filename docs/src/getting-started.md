# Getting Started

ATP provides multiple ways to interact with its text processing capabilities:

- **CLI** — Command-line interface for scripting and terminal use
- **TUI** — Terminal-based interactive UI
- **GUI** — Desktop graphical interface
- **WASM** — Browser-based usage via WebAssembly
- **LSP** — Editor integration for AQL files

Start with the [Installation](./getting-started/installation.md) guide, then follow the [Quick Start](./getting-started/quick-start.md) tutorial.

If you are building an AI agent, see [For AI Agents](./getting-started/ai-agents.md).
